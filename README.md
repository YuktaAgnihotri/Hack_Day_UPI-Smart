# 💸 UPI Smart — AI Expense Intelligence

> **Turn payment screenshots into smart financial insights — instantly.**

---

## 🚀 Overview

**UPI Smart** is an AI-powered expense intelligence tool designed for the modern digital spender.
Instead of manually tracking expenses or relying on bank integrations, UPI Smart works with **real-world, messy data** — screenshots, chats, and fragmented transactions.

Just upload a payment screenshot, and the system automatically extracts, categorizes, and visualizes your expenses.

---

## ✨ Key Features

* 📸 **Screenshot to Insights**
  Upload any payment screenshot → get structured expense data instantly

* 🧠 **AI-Powered Extraction**
  Detects amount, merchant, and date using intelligent parsing

* 🏷️ **Auto Categorization**
  Expenses grouped into categories like Food, Travel, Shopping

* 📊 **Visual Dashboard**
  Clean and simple charts to understand spending patterns

* ⚡ **Zero Manual Entry**
  No typing, no tracking — fully automated

* React.js / Next.js
* Tailwind CSS

**Backend**

* Node.js / Express

**AI & Processing**

* Gemini API (multimodal AI)
* OCR + Prompt Engineering

**Database**

* MongoDB / Firebase (based on implementation)

---

## ⚙️ How It Works

1. User uploads a payment screenshot
2. Image is processed using AI + OCR
3. Relevant data is extracted (amount, merchant, date)
4. Expense is categorized automatically
5. Insights are displayed via dashboard

## 🧪 Setup & Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/upi-smart.git
cd upi-smart
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Add Environment Variables

Create a `.env` file in the root:

```env
GEMINI_API_KEY=your_api_key_here
```

### 4. Run the Development Server

```bash
npm run dev
```

App will run on:

```
http://localhost:3000
```
